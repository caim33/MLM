## 运行环境与命令

环境为 4 张 NVIDIA A100-SXM4-40GB、CUDA Torch 2.4、Transformers 4.57.3、
PEFT 0.18.0、Accelerate 1.14.0、PyAV 12.3.0。smoke 使用物理 GPU 1；GPU 0
保留给受管理的 keepalive。

```bash
export MOTIONLLM_ROOT=/wangbenyou-sulongjie/caimeng/qwen-codebase
export MOTIONLLM_RUNTIME=/wangbenyou-sulongjie/caimeng/runtime/qwen-codebase-clean-py310
export PYTHONPATH="$MOTIONLLM_RUNTIME:$MOTIONLLM_ROOT/src:$MOTIONLLM_ROOT"
export CHECKPOINT_OVERLAY=/wangbenyou-sulongjie/caimeng/runtime/checkpoint-overlays/qa374_sft_step3best_checkpoint-48_merged_full
cd "$MOTIONLLM_ROOT"

CUDA_VISIBLE_DEVICES=1 python3 qwenvl/infer/infer_qwen3_vl_motion.py \
  --model_name_or_path "$CHECKPOINT_OVERLAY" \
  --test_data_path /wangbenyou-sulongjie/caimeng/runtime/smoke-results/qa374_vm_sample1_clean_prompt.json \
  --data_path /wangbenyou-sulongjie/Motion-r1/data/motionx_374 \
  --motion_mean_path /wangbenyou-sulongjie/qwen-vl-finetune/qwenvl/data/Mean.npy \
  --motion_std_path /wangbenyou-sulongjie/qwen-vl-finetune/qwenvl/data/Std.npy \
  --output_path /wangbenyou-sulongjie/caimeng/runtime/smoke-results/qa374_checkpoint48_vm_sample1.jsonl \
  --num_samples 1 --max_new_tokens 32 --batch_size 1 --device cuda
```
