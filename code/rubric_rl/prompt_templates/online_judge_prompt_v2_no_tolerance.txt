Judging principles:
1. Evaluate visible final answer content separately from visible reasoning or think content.
2. Reasoning exists only inside exactly one non-empty, lowercase <think>...</think> block. If that structure is absent or malformed, all reasoning criteria are missed.
3. For final-answer facts, accept semantic paraphrases.
4. Use the source trust hierarchy encoded in the criteria:
   - Motion-grounded numeric kinematics, laterality, camera-relative orientation, and numerically supported body configuration are authoritative.
   - Video/final summary is preferred for high-level activity semantics, scene/context, objects, broad temporal/action semantics, and person-object interactions.
   - Wrong numeric values, wrong laterality, and wrong camera-relative orientation are source contradictions.
5. For basic_action_facts and body_configuration:
   - present_ids means the fact appears anywhere in the candidate.
   - aligned_ids means the fact appears in the correct segment, nearby segment, or a reasonable merged segment.
   - missed_ids means the fact is absent.
   - misplaced_ids means the fact appears, but in a clearly wrong temporal phase.
   - Generic routine-level phrases such as "sometimes upright", "does footwork", or "arms move" are not enough for aligned_ids unless tied to the correct time range or ordered phase.
   - Do not mark every segment correct from one broad summary sentence.
6. For numeric_kinematics, exact equality is not required.
   Use these deterministic tolerance rules by unit:
   - degrees: strict +/-10, loose +/-20
   - m: strict +/-0.05, loose +/-0.10
   - s: strict +/-0.20, loose +/-0.50
   Then assign:
   - strict_value_match_ids: candidate value is within target_range plus strict tolerance.
   - loose_value_match_ids: candidate value is outside strict tolerance but within loose tolerance.
   - semantic_present_ids: the same segment/phase mentions the correct body part and measured quantity or directly implied numeric state, even if no close numeric value is given.
   - wrong_value_ids: candidate gives a value outside loose tolerance or reverses the numeric meaning.
   - missed_ids: candidate omits that numeric quantity/state.
   - These five lists are pairwise disjoint and together contain every numeric criterion ID exactly once. semantic_present_ids is only for a measurement mentioned without a numeric value.
   - Quoted, negated, hypothetical, uncertain, meta-level, or immediately corrected values are not strict or loose evidence.
7. Do not assign semantic_present_ids from generic statements like "the torso is sometimes upright/folded" or "the legs alternate".
8. Missing numeric values are omissions, not hallucinations.
9. Distinguish limb location from joint straightness: "leg extends behind" can describe location and should not be treated as "knee is straight" unless the candidate explicitly claims a straight knee.
10. For laterality, judge anatomical left/right body parts using the motion-grounded criteria.
11. For camera_relative_orientation, judge orientation relative to the camera or screen, not anatomical left/right.
12. If criterion wording and target_range conflict, trust target_range.
13. Use only IDs that exist in the criteria. Never invent IDs.
14. Every categorical set is an exact partition: global satisfied/missed; basic and body present/missed plus aligned/misplaced over present; laterality correct/wrong/missed; orientation correct/wrong/missed; reasoning satisfied/missed/contradicted. Never repeat an ID across alternatives and never omit an eligible ID.
15. Do not output a binding field. The trusted host adds the sample/criteria/candidate/nonce binding after local generation.
16. Do not return counts or compute reward.

- 0: order is absent, reversed, or mostly wrong.

Language format score is an integer from 0 to 10.
