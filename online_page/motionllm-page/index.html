EXECUTIVE VERDICT

先看五个判断

如果只读这一屏，它应该能改变下一轮实验设计。

01

最大瓶颈更像“对齐”，不是“推理长度”

motion 经 VQ-VAE 后被插值到文本占位长度，再由两层 MLP 投到 LLM 隐空间。先证明这些 embedding 保留了节奏、左右、局部关节与阶段边界，再扩 GRPO。

02

VM/V 奖励不是因果的“使用 motion”证明

当前 bonus 奖励“VM 组均值不低于 V”，但正确答案仍可能来自视频捷径。应加入反事实 motion、时间打乱与同视频错 motion 三类 hard negative。

03

训练格式与正式评估协议还没完全同构

奖励与部分评估代码会在 <answer> 内兜底提取独立 A-D；正式主表只接受完整的单字母标签。训练期就应使用同一 parser。

04

Rubric 已有好骨架，但缺“校准层”

细粒度动作、身体、数值、左右、时序和推理拆分是优势；但空 criterion 会拿满该维度，judge 也没有 schema 校验、重试、双评审或人类校准集。

05

下一轮应做最小可证伪实验，而不是再堆模型

围绕 motion 表示、模态增益、奖励鲁棒性、严格生成四条假设做 2×2/消融；每条都冻结数据、parser、seed 和当前批 checkpoint。

EXPERIMENT ROADMAP

按证据价值排序的优化路线

每一步都有可证伪的判断标准；不把“训练跑通”当成“方法有效”。

P01–2 周

先建立四个不依赖大规模 RL 的诊断

  • Motion probe：冻结模型，用 embedding 预测左右、速度、身体部位、阶段边界；与 raw motion / VQ code / projector 后表示对比。
  • Counterfactual VM：原 motion、时间打乱、同类错 motion、全零 motion；报告 Δaccuracy 与 flip matrix。
  • Strict parser parity：reward、离线 eval、统一主表只调用同一正则和错误枚举。
  • Rubric calibration：先做 100–200 条双人标注集，测 judge 的维度级准确率、方差和顺序偏差。
通过条件
motion 反事实显著影响 motion-dependent 子集，且不伤 non-motion 子集
P12–4 周

重做 motion–LLM 对齐，而不是直接重训全部参数

  • 比较 continuous projector、离散 motion code token、Q-Former/resampler 三种接口。
  • 让 token 数由 motion 时间结构决定，并显式带 frame/time position；禁止由 prompt 占位数决定。
  • 先做 motion-only caption/QA 对齐，再做 VM instruction mix；按任务和模态控制 batch 比例。
  • 用 hard negative 学“motion 与 video 是否一致”，再进入答案 RL。
通过条件
probe + counterfactual + MoVid/Motion QA 同时改善
P24–8 周

把 GRPO 从“答案奖励”升级为“受控的信息增益奖励”

  • 保留 verifiable answer/format reward，把 VM gain 单独作为条件奖励并做组内归一化。
  • 只在经标注的 motion-dependent 样本上施加模态增益奖励；其他样本不强迫 motion 胜过 video。
  • 对 rubric reward 做 judge ensemble / random order / held-out calibration；监控 reward–human gap。
  • 跟踪 entropy、clip fraction、zero-variance groups、长度、invalid rate，而不只看平均 reward。
通过条件
held-out 严格生成主指标提升，且 reward hacking 套件不退化

EVIDENCE & SCOPE

这份网页如何得出结论

01 · 代码优先

先追踪 snapshot 的 forward、数据处理、reward、runner、rubric post-process 与 evaluator，再选择论文。代码证据链接到页面内的现行代码索引，并标出路径与行号。

02 · 一手论文

摘要只用于初筛；入选条目核对论文 PDF 的方法、实验、局限和主图。外链优先 arXiv、会议页与官方代码仓库。

03 · 明确区分

“直接竞争”表示任务/模态/输出高度重合；“直接借鉴”表示可移植机制；“基础/邻近”只解决上游表示或评估，不冒充端到端方案。

04 · 评估边界

历史 checkpoint、accuracy、prediction、proxy、option-score 不进入新批主结果。任何下一批都必须先完成所有模型的 fresh finetune / blocked barrier。
