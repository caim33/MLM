Mesh Accuracy

网格保留主要关节旋转、根节点朝向和垂直位移；水平轨迹逐帧居中。人体比例来自 neutral SMPL-H，它不是源数据提供的 mesh。

Hands & Shape

pose_hand 与 betas 当前均为零；手型和体型保持 neutral，不恢复细粒度手指动作。

License Boundary

服务端计算并向私有浏览器发送派生顶点与拓扑；不下发 SMPL-H model、blend shapes 或 skinning weights。

07 · DATA INTEGRITY

Data Quality

“不可渲染”不等于动作无效。媒体缺失、标注缺失、格式未接入和许可证限制分别记录。

Cleanup Boundary

极少量 annotation-only ID 已单独审计；MotionX 30 条缺 frame caption 的 motion 保留，不以删除动作换取表面上的 100% 覆盖。

08 · METHODOLOGY

Methods

Keys

HumanML3D / SONIC 使用 motion stem；MotionX video stem 去除全部下划线后与 motion ID 对齐。

Duration

sum(frames / fps)；HumanML3D 为 20 FPS，SONIC 与 MotionX 为 30 FPS。Video–text 未批量探测全部容器时长。

Text Units

caption file、caption line、temporal event、frame description 与 CoT record 分开计数。

Publishing

SMPL-H 模型仅在服务器内部使用；公开部署或分发派生网格前需要重新确认许可证。
