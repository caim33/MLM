# DeepSeek study report

Public route: https://caim33.github.io/MLM/deepseek/

The original local 36-page report is arranged as static semantic HTML. It retains
the authored body, tables, equations, reference library and the original PDF.
Twenty-six numbered figures have source links, five-part reading guides and a
local enlargement dialog. The source PDF contains 24 figures; two additional
official performance figures already collected with that report are included.

The report snapshot is 2026-10-26. The web edition and primary-source review are
dated 2026-11-17. Additions clarify version boundaries, pretraining recipes,
performance metrics, bounded replay and speculative-decoding assumptions.
Mutable official repository links are identified as current entry points.

DeepInfer uses commit `553741557a57df44a46fb3ab72b6aafeaf945337`.
Flash-1017 config and reference model links use revision
`08c8657f02291e11b6f6b63e0e16014f8e748518`.

The KV calculator, binary group-reward example and four-GPU FSDP/EP walkthrough
are teaching examples. They do not represent measured cluster results. V3's
reported ZeRO-1 DP configuration is kept distinct from the FSDP illustration.
Assets and navigation use relative paths, so the page works under the MLM prefix.
